# Portfolio Templates

Two free portfolio website templates made with plain **HTML and CSS**. No JavaScript, no frameworks, no build tools. Open `index.html` in your browser and it works.

| Template | Folder | Style |
|---|---|---|
| Simple | [`portfolio-template-simple`](portfolio-template-simple) | One page: home, about, skills, projects, contact. Teal color. |
| Classic | [`portfolio-template-classic`](portfolio-template-classic) | Adds education, achievements and experience. Light and dark mode button. Warm gold color. |

Both are mobile friendly and written to be neutral, so anyone can use them.

## How to use

1. Click **Use this template** (green button at the top of the repo), or download the ZIP.
2. Pick one template folder.
3. Open its `index.html` in a code editor.
4. Follow the README inside that folder to add your own info.
5. Publish it for free with **GitHub Pages** (Settings → Pages).

## A note

These templates were built with help from AI tools and then checked by hand.
